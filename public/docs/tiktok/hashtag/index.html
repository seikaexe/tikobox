GET/api/hashtag
GET/api/hashtag/{name}

Mengambil informasi dan statistik satu hashtag dari halaman tag TikTok. Daftar video milik hashtag tidak tersedia

Parameter#

ParameterTipeWajibKeterangan
namestringwajibNama hashtag, dengan atau tanpa #. Query hashtag diterima sebagai alias. Pada bentuk path /api/hashtag/{name}, nama ditulis langsung di URL

Aturan nama: 1 sampai 100 karakter berupa huruf (termasuk huruf non-Latin), angka, dan underscore

Karakter # pada URL dianggap fragment oleh browser dan HTTP client. Tulis tanpa # atau encode menjadi %23

Contoh Request#

cURL
curl -sS -G "https://tikobox.my.id/api/hashtag" \
  -A "MyTikoboxClient/1.0" \
  --data-urlencode "name=fyp"
Fetch
const url = new URL("https://tikobox.my.id/api/hashtag")
url.searchParams.set("name", "fyp")

const res = await fetch(url)
const json = await res.json()

if (json.code !== 0) throw new Error(`${res.status} ${json.msg}`)
console.log(json.data)
Node.js
const url = new URL("https://tikobox.my.id/api/hashtag")
url.searchParams.set("name", "fyp")

const res = await fetch(url, { headers: { "User-Agent": "MyTikoboxClient/1.0" } })
const json = await res.json()

if (json.code !== 0) throw new Error(`${res.status} ${json.msg}`)
console.log(json.data)
Python
import requests

res = requests.get(
    "https://tikobox.my.id/api/hashtag",
    params={
        "name": "fyp",
    },
    headers={"User-Agent": "MyTikoboxClient/1.0"},
    timeout=35,
)

data = res.json()

if data["code"] != 0:
    raise RuntimeError(f'{res.status_code} {data["msg"]}')

print(data["data"])
PHP
<?php

$query = http_build_query([
    "name" => "fyp",
]);

$ch = curl_init("https://tikobox.my.id/api/hashtag" . "?" . $query);
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_TIMEOUT => 35,
    CURLOPT_USERAGENT => "MyTikoboxClient/1.0",
]);

$body = curl_exec($ch);
if ($body === false) {
    throw new RuntimeException(curl_error($ch));
}

$status = curl_getinfo($ch, CURLINFO_RESPONSE_CODE);
$json = json_decode($body, true);

if (($json["code"] ?? -1) !== 0) {
    throw new RuntimeException($status . " " . ($json["msg"] ?? "error"));
}

print_r($json["data"]);

Field data#

FieldTipeKeterangan
idstringID hashtag
namestringNama hashtag
descriptionstringDeskripsi, kosong bila tidak ada
stats.video_countnumberJumlah video yang memakai hashtag
stats.view_countnumberTotal views
urlstringLink hashtag di TikTok

Sumber Data dan Batasan#

  • Angka berasal dari halaman tiktok.com/tag/nama pada saat request. Nilainya bisa berbeda dengan yang tampil di aplikasi TikTok atau pada waktu lain, karena TikTok memperbarui dan membulatkan statistik dengan caranya sendiri
  • Angka yang tidak tersedia ditulis 0
  • Struktur halaman TikTok dapat berubah dan TikTok dapat menampilkan captcha ke server. Request bisa gagal sewaktu-waktu
  • Statistik lain seperti tren harian atau daftar video tidak tersedia
