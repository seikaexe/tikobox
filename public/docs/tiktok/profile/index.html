GET/api/user
GET/api/user/{username}
GET/api/@{username}

Mengambil informasi profil publik dari halaman akun TikTok. Ketiga bentuk URL menghasilkan response yang sama

Parameter#

ParameterTipeWajibKeterangan
unique_idstringwajibUsername, dengan atau tanpa @. Query username diterima sebagai alias. Pada bentuk path /api/user/{username} dan /api/@{username}, username ditulis langsung di URL

Aturan username: 1 sampai 24 karakter dari huruf, angka, titik, dan underscore

Contoh Request#

cURL
curl -sS -G "https://tikobox.my.id/api/user" \
  -A "MyTikoboxClient/1.0" \
  --data-urlencode "unique_id=username"
Fetch
const url = new URL("https://tikobox.my.id/api/user")
url.searchParams.set("unique_id", "username")

const res = await fetch(url)
const json = await res.json()

if (json.code !== 0) throw new Error(`${res.status} ${json.msg}`)
console.log(json.data)
Node.js
const url = new URL("https://tikobox.my.id/api/user")
url.searchParams.set("unique_id", "username")

const res = await fetch(url, { headers: { "User-Agent": "MyTikoboxClient/1.0" } })
const json = await res.json()

if (json.code !== 0) throw new Error(`${res.status} ${json.msg}`)
console.log(json.data)
Python
import requests

res = requests.get(
    "https://tikobox.my.id/api/user",
    params={
        "unique_id": "username",
    },
    headers={"User-Agent": "MyTikoboxClient/1.0"},
    timeout=35,
)

data = res.json()

if data["code"] != 0:
    raise RuntimeError(f'{res.status_code} {data["msg"]}')

print(data["data"])
PHP
<?php

$query = http_build_query([
    "unique_id" => "username",
]);

$ch = curl_init("https://tikobox.my.id/api/user" . "?" . $query);
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_TIMEOUT => 35,
    CURLOPT_USERAGENT => "MyTikoboxClient/1.0",
]);

$body = curl_exec($ch);
if ($body === false) {
    throw new RuntimeException(curl_error($ch));
}

$status = curl_getinfo($ch, CURLINFO_RESPONSE_CODE);
$json = json_decode($body, true);

if (($json["code"] ?? -1) !== 0) {
    throw new RuntimeException($status . " " . ($json["msg"] ?? "error"));
}

print_r($json["data"]);
Bentuk path
curl -sS -A "MyTikoboxClient/1.0" "https://tikobox.my.id/api/@username"

Sumber Data dan Batasan#

  • Data diambil dari halaman publik tiktok.com/@username, tanpa login dan tanpa layanan pihak ketiga
  • created_at memakai waktu pembuatan dari TikTok. Bila kosong, waktu dihitung dari User ID akun
  • Waktu perubahan nickname dan username kosong bila akun belum pernah mengubahnya atau TikTok tidak menyediakannya
  • Angka yang tidak tersedia ditulis 0, sehingga 0 tidak selalu berarti benar-benar nol
  • Struktur halaman TikTok dapat berubah dan TikTok dapat menampilkan captcha ke server. Field bisa kosong dan request bisa gagal sewaktu-waktu
  • Hanya data publik yang tersedia, tidak ada email, nomor telepon, atau data privat
