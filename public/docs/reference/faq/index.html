Tidak. Lihat Autentikasi

Kenapa fetch dari website saya gagal dengan error CORS?#

API tidak mengirim header CORS. Panggil dari backend kamu, lalu kirim hasilnya ke frontend

Kenapa saya kena 429 padahal baru sedikit request?#

Profil, hashtag, dan video berbagi satu jatah per menit. Klien otomatis (termasuk curl dan library HTTP tanpa User-Agent sendiri) mendapat batas lebih rendah. Lihat Rate Limit

Apakah ada batas ukuran atau jumlah download?#

Tidak ada batas ukuran file atau durasi. Yang ada hanya rate limit per menit

Bagaimana mendapatkan video dengan watermark?#

Pakai data.wmplay. Bila TikTok tidak menyediakan versi watermark, nilainya sama dengan data.play

Kenapa URL video tidak bisa dibuka lagi setelah beberapa waktu?#

URL media dari TikTok memiliki masa berlaku. Ambil ulang lewat /api/tiktok

Kenapa sering muncul error captcha?#

TikTok dapat menantang permintaan dari server. Ulangi beberapa saat kemudian. Ini lebih sering terjadi pada endpoint profil dan hashtag karena memakai halaman publik TikTok
