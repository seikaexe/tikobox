Envelope#

Sukses
{
  "code": 0,
  "msg": "success",
  "processed_time": 1.2345,
  "data": {}
}
Gagal
{
  "code": -1,
  "msg": "pesan error"
}
FieldTipeKeterangan
codenumber0 sukses, -1 gagal
msgstringsuccess atau pesan error
processed_timenumberLama proses dalam detik. Ada pada response lookup, tidak ada pada health dan info
dataobjectIsi hasil, hanya ada saat sukses

Data Video#

Untuk /api/tiktok

FieldTipeKeterangan
idstringID video
regionstringKode wilayah pembuatan, kosong bila tidak ada
titlestringCaption video
coverstringURL gambar cover
origin_coverstringURL cover asli
durationnumberDurasi, 0 bila tidak tersedia
playstringURL MP4 tanpa watermark (kualitas standar)
wmplaystringURL MP4 dengan watermark. Sama dengan play bila versi watermark tidak ada
hdplaystringURL MP4 HD. Sama dengan play bila HD tidak ada
sizenumberUkuran play dalam byte, 0 bila tidak diketahui
wm_sizenumberUkuran wmplay dalam byte
hd_sizenumberUkuran hdplay dalam byte
create_timenumberWaktu posting, Unix timestamp
authorobjectid, unique_id, nickname, avatar
cookiestringHanya ada bila TikTok memberi cookie sesi. Teruskan ke /api/download lewat parameter c
FieldTipeKeterangan
musicstringURL audio. Lihat Audio
music_infoobjectid, title, play, cover, author, original, duration, album
play_countnumberJumlah ditonton
digg_countnumberJumlah like
comment_countnumberJumlah komentar
share_countnumberJumlah dibagikan
collect_countnumberJumlah disimpan
download_countnumberSelalu 0
imagesstring[]Hanya ada pada postingan foto. Lihat Slideshow

Konvensi#

  • Field string yang tidak tersedia berisi string kosong, bukan null
  • Field angka yang tidak tersedia berisi 0
  • Field opsional (images, cookie) tidak ada sama sekali saat tidak tersedia
  • Urutan field di JSON tidak dijamin, akses berdasarkan nama
