Perlindungan di Server#

AreaPenerapan
Validasi inputLink TikTok dan URL media divalidasi dengan allowlist host, hanya http atau https, tanpa kredensial dan tanpa port
SSRFRedirect diikuti manual, setiap hop divalidasi, dan DNS harus mengarah ke IP publik
Tipe fileHanya video, audio, dan gambar rasteri yang diproxy. SVG dan HTML ditolak
Nama fileDisaring menjadi karakter aman sehingga tidak bisa memuat path atau karakter kontrol
Header keamananHelmet dan Content-Security-Policy. File hasil proxy dikirim dengan CSP sandbox dan nosniff
LogKejadian keamanan dicatat tanpa cookie, query, dan header, dengan IP disamarkan
ErrorPesan error disaring agar tidak membocorkan jalur file atau detail jaringan

Batasan Teknis#

HalNilai
Panjang URL request2500 karakter
Panjang link TikTok500 karakter (teks input dipotong di 1000 karakter)
Panjang URL media2000 karakter
Timeout lookup28 detik
Timeout header dari TikTok saat unduh15 detik
Maksimal redirect saat unduh3
Ukuran file unduhanTidak dibatasi
MethodGET, HEAD, OPTIONS
CORSTidak ada header CORS

Saran untuk Integrator#

  • Panggil API dari backend, bukan dari browser pengguna
  • Jangan menyimpan URL media untuk jangka panjang, masa berlakunya ditentukan TikTok
  • Perlakukan data.cookie sebagai data sementara dan jangan dibagikan ke pihak lain
  • Batasi jumlah percobaan ulang dan hormati retry-after
  • Gunakan konten hanya sesuai hak dan kebijakan platform serta hukum yang berlaku
