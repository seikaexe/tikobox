Status Code

Status HTTP yang dikembalikan API

StatusArtiKapan
200OKRequest berhasil
204No ContentResponse untuk OPTIONS, dengan header allow: GET, HEAD, OPTIONS
400Bad RequestLink atau URL media tidak valid, atau parameter path tidak bisa di-decode
403ForbiddenScanner keamanan, atau /api/download dipanggil lintas situs dari browser
404Not FoundProfil atau hashtag tidak ditemukan atau input salah
405Method Not AllowedMethod selain GET, HEAD, OPTIONS
414URI Too LongURL lebih dari 2500 karakter
429Too Many RequestsMelewati rate limit, baca retry-after
500Internal Server ErrorKesalahan server tak terduga, msg Terjadi kesalahan pada server
502Bad GatewayTikTok gagal diakses, data tidak tersedia, atau diblokir
504Gateway TimeoutProses lookup melebihi 28 detik
