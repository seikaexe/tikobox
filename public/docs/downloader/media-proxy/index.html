GET/api/download

Meneruskan (stream) file video, audio, atau gambar dari CDN TikTok. Tidak ada transcoding, kompresi, atau pengubahan isi file. Endpoint ini dipakai tombol unduh di website Tikobox

Parameter Query#

ParameterTipeWajibKeterangan
urlstringwajibURL media dari CDN TikTok, maksimal 2000 karakter
namestringopsionalNama file untuk content-disposition. Karakter selain huruf, angka, _, ., - diganti _, maksimal 80 karakter, default tikobox
cstringopsionalCookie dari data.cookie. Hanya karakter ASCII yang bisa dicetak, maksimal 2000 karakter
inlinestringopsionalIsi 1 agar file ditampilkan di browser (inline), selain itu menjadi attachment

Host yang Diizinkan#

Hanya host berikut (dan subdomainnya) lewat http atau https, tanpa username, password, atau port:

  • tiktokcdn.com
  • tiktokcdn-us.com
  • tiktokcdn-eu.com
  • tiktokv.com
  • tiktokv.us
  • tiktokv.eu
  • byteoversea.com
  • ibytedtos.com
  • muscdn.com
  • tiktok.com

Contoh Request#

cURL
curl -sS -f -G "https://tikobox.my.id/api/download" \
  -A "MyTikoboxClient/1.0" \
  --data-urlencode "url=https://v16m.tiktokcdn.com/xxxx/video.mp4" \
  --data-urlencode "name=video.mp4" \
  -o "video.mp4"
Fetch
const url = new URL("https://tikobox.my.id/api/download")
url.searchParams.set("url", "https://v16m.tiktokcdn.com/xxxx/video.mp4")
url.searchParams.set("name", "video.mp4")

const res = await fetch(url)
if (!res.ok) throw new Error((await res.json()).msg)

const blob = await res.blob()
console.log(blob.type, blob.size)
Node.js
import { createWriteStream } from "node:fs"
import { Readable } from "node:stream"
import { pipeline } from "node:stream/promises"

const url = new URL("https://tikobox.my.id/api/download")
url.searchParams.set("url", "https://v16m.tiktokcdn.com/xxxx/video.mp4")
url.searchParams.set("name", "video.mp4")

const res = await fetch(url, { headers: { "User-Agent": "MyTikoboxClient/1.0" } })
if (!res.ok) throw new Error((await res.json()).msg)

await pipeline(Readable.fromWeb(res.body), createWriteStream("video.mp4"))
console.log("tersimpan:", "video.mp4")
Python
import requests

res = requests.get(
    "https://tikobox.my.id/api/download",
    params={
        "url": "https://v16m.tiktokcdn.com/xxxx/video.mp4",
        "name": "video.mp4",
    },
    headers={"User-Agent": "MyTikoboxClient/1.0"},
    stream=True,
    timeout=35,
)

if not res.ok:
    raise RuntimeError(res.json()["msg"])

with open("video.mp4", "wb") as f:
    for chunk in res.iter_content(chunk_size=65536):
        f.write(chunk)
PHP
<?php

$query = http_build_query([
    "url" => "https://v16m.tiktokcdn.com/xxxx/video.mp4",
    "name" => "video.mp4",
]);

$ch = curl_init("https://tikobox.my.id/api/download" . "?" . $query);
$file = fopen("video.mp4", "wb");

curl_setopt_array($ch, [
    CURLOPT_FILE => $file,
    CURLOPT_FOLLOWLOCATION => false,
    CURLOPT_TIMEOUT => 0,
    CURLOPT_USERAGENT => "MyTikoboxClient/1.0",
]);

if (!curl_exec($ch)) {
    throw new RuntimeException(curl_error($ch));
}

$status = curl_getinfo($ch, CURLINFO_RESPONSE_CODE);
fclose($file);

if ($status !== 200) {
    unlink("video.mp4");
    throw new RuntimeException("HTTP $status");
}

Response Sukses#

Status 200 dengan body berupa file. Header yang dikirim:

HeaderIsi
content-typeDari TikTok. Diizinkan: video/*, audio/*, gambar (jpeg, png, webp, gif, avif, heic), application/octet-stream
content-lengthAda bila TikTok mengirimkannya
content-dispositionattachment atau inline, beserta nama file
cache-controlno-store
x-content-type-optionsnosniff
content-security-policydefault-src 'none'; sandbox

Response Error#

Error tetap berupa JSON, bukan file

400
{
  "code": -1,
  "msg": "URL media tidak diizinkan."
}
StatusmsgPenyebab
400URL media tidak diizinkan.Host tidak ada di daftar, URL terlalu panjang, atau redirect ke tujuan yang ditolak
403Akses ditolak.Browser mengirim sec-fetch-site: cross-site, yaitu dipanggil dari halaman situs lain
502Gagal mengambil file dari provider (HTTP 403).TikTok menolak permintaan. Angka mengikuti status dari TikTok
502Tipe file tidak didukung.Tipe konten dari TikTok bukan video, audio, atau gambar yang diizinkan
502Gagal mengambil file, coba lagi.Koneksi ke TikTok gagal
429Terlalu banyak permintaan. Coba lagi sebentar lagi.Melewati batas request, lihat Rate Limit
405Metode tidak diizinkan.Metode selain GET, HEAD, atau OPTIONS
414URL terlalu panjang.Panjang URL request lebih dari 2500 karakter

Catatan#

  • Tidak ada batas ukuran file maupun durasi. Yang dibatasi hanya jumlah request, lihat Rate Limit
  • Batas waktu menunggu header dari TikTok adalah 15 detik. Lama unduhan sendiri tidak dibatasi
  • Panjang total URL request maksimal 2500 karakter. Cookie panjang yang di-encode bisa melewati batas ini sehingga status 414. Cookie bersifat opsional
  • Header Range tidak diteruskan, jadi resume unduhan tidak didukung
  • HEAD mengembalikan header tanpa mengunduh file
  • Pemanggilan dari browser di domain lain diblokir. Gunakan dari server kamu
