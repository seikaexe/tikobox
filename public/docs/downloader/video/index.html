GET/api/tiktok

Mengambil data satu link TikTok: URL video (tanpa watermark, watermark, HD), cover, statistik, penulis, dan musik. Link foto dan slideshow memakai endpoint yang sama, lihat Slideshow

Parameter Query#

ParameterTipeWajibKeterangan
urlstringwajibLink TikTok. Boleh tanpa https:// dan boleh ada teks lain di sekitarnya, link pertama akan diambil

Link yang Didukung#

HostContoh
tiktok.comhttps://www.tiktok.com/@user/video/7300000000000000000
vt.tiktok.comhttps://vt.tiktok.com/ZSxxxxxxx/
vm.tiktok.comhttps://vm.tiktok.com/ZSxxxxxxx/
tt.site, www.tt.sitehttps://www.tt.site/t/xxxx
  • Subdomain *.tiktok.com dan m.tiktok.com juga diterima
  • Link dengan username dan password (user:pass@host) atau port eksplisit ditolak
  • Panjang link maksimal 500 karakter

Contoh Request#

cURL
curl -sS -G "https://tikobox.my.id/api/tiktok" \
  -A "MyTikoboxClient/1.0" \
  --data-urlencode "url=https://vt.tiktok.com/ZSxxxxxxx/"
Fetch
const url = new URL("https://tikobox.my.id/api/tiktok")
url.searchParams.set("url", "https://vt.tiktok.com/ZSxxxxxxx/")

const res = await fetch(url)
const json = await res.json()

if (json.code !== 0) throw new Error(`${res.status} ${json.msg}`)
console.log(json.data)
Node.js
const url = new URL("https://tikobox.my.id/api/tiktok")
url.searchParams.set("url", "https://vt.tiktok.com/ZSxxxxxxx/")

const res = await fetch(url, { headers: { "User-Agent": "MyTikoboxClient/1.0" } })
const json = await res.json()

if (json.code !== 0) throw new Error(`${res.status} ${json.msg}`)
console.log(json.data)
Python
import requests

res = requests.get(
    "https://tikobox.my.id/api/tiktok",
    params={
        "url": "https://vt.tiktok.com/ZSxxxxxxx/",
    },
    headers={"User-Agent": "MyTikoboxClient/1.0"},
    timeout=35,
)

data = res.json()

if data["code"] != 0:
    raise RuntimeError(f'{res.status_code} {data["msg"]}')

print(data["data"])
PHP
<?php

$query = http_build_query([
    "url" => "https://vt.tiktok.com/ZSxxxxxxx/",
]);

$ch = curl_init("https://tikobox.my.id/api/tiktok" . "?" . $query);
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_TIMEOUT => 35,
    CURLOPT_USERAGENT => "MyTikoboxClient/1.0",
]);

$body = curl_exec($ch);
if ($body === false) {
    throw new RuntimeException(curl_error($ch));
}

$status = curl_getinfo($ch, CURLINFO_RESPONSE_CODE);
$json = json_decode($body, true);

if (($json["code"] ?? -1) !== 0) {
    throw new RuntimeException($status . " " . ($json["msg"] ?? "error"));
}

print_r($json["data"]);

Field data

regionstringKode wilayah pembuatan, kosong bila tidak ada

durationnumberDurasi, 0 bila tidak tersedia
playstringURL MP4 tanpa watermark (kualitas standar)

Daftar lengkap termasuk music_info, statistik, dan images ada di Format Response

Bentuk Singkat#

GET/api/{link}

Link bisa ditempel langsung setelah /api/. Hasilnya sama persis dengan /api/tiktok, begitu juga /api/?url=LINK

cURL
curl -sS -A "MyTikoboxClient/1.0" "https://tikobox.my.id/api/https://vt.tiktok.com/ZSxxxxxxx/"
Path yang tidak dikenali di bawah /api/ diperlakukan sebagai link TikTok sehingga mengembalikan status 400 dengan pesan link tidak valid, bukan 404

Catatan#

  • Data diambil langsung dari halaman TikTok. Video privat, dihapus, atau dibatasi wilayah tidak bisa diambil
  • URL media memiliki masa berlaku dari TikTok, unduh segera lewat Media Proxy
  • download_count selalu 0 karena tidak disediakan oleh sumber data
  • Response tidak di-cache (cache-control: no-store)
  • Batas waktu proses 28 detik
