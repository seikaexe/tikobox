Audio Downloader

Ambil musik atau suara dari video TikTok

Di halaman ini
  • Field Audio
  • Alur
  • Contoh Unduh Audio
  • Response Error

Audio tidak punya endpoint sendiri. URL audio ada di response /api/tiktok pada field music dan music_info.play, lalu diunduh lewat /api/download

Field Audio#

FieldTipeKeterangan
musicstringURL audio, kosong bila tidak tersedia
music_info.idstringID musik
music_info.titlestringJudul musik
music_info.playstringURL audio, sama dengan music
music_info.coverstringURL cover musik
music_info.authorstringNama pembuat musik
music_info.originalbooleanSuara asli dari pembuat video
music_info.durationnumberDurasi musik
music_info.albumstringNama album, kosong bila tidak ada

Alur#

  1. Panggil /api/tiktok lalu ambil data.music
  2. Pastikan nilainya tidak kosong
  3. Unduh lewat /api/download dengan name berakhiran .mp3
Bila name berakhiran .mp3, server memaksa content-type: audio/mpeg agar file tidak tersimpan sebagai .mp3.mp4

Contoh Unduh Audio#

cURL
curl -sS -f -G "https://tikobox.my.id/api/download" \
  -A "MyTikoboxClient/1.0" \
  --data-urlencode "url=https://sf16.tiktokcdn.com/xxxx/music.mp3" \
  --data-urlencode "name=audio.mp3" \
  -o "audio.mp3"
Fetch
const url = new URL("https://tikobox.my.id/api/download")
url.searchParams.set("url", "https://sf16.tiktokcdn.com/xxxx/music.mp3")
url.searchParams.set("name", "audio.mp3")

const res = await fetch(url)
if (!res.ok) throw new Error((await res.json()).msg)

const blob = await res.blob()
console.log(blob.type, blob.size)
Node.js
import { createWriteStream } from "node:fs"
import { Readable } from "node:stream"
import { pipeline } from "node:stream/promises"

const url = new URL("https://tikobox.my.id/api/download")
url.searchParams.set("url", "https://sf16.tiktokcdn.com/xxxx/music.mp3")
url.searchParams.set("name", "audio.mp3")

const res = await fetch(url, { headers: { "User-Agent": "MyTikoboxClient/1.0" } })
if (!res.ok) throw new Error((await res.json()).msg)

await pipeline(Readable.fromWeb(res.body), createWriteStream("audio.mp3"))
console.log("tersimpan:", "audio.mp3")
Python
import requests

res = requests.get(
    "https://tikobox.my.id/api/download",
    params={
        "url": "https://sf16.tiktokcdn.com/xxxx/music.mp3",
        "name": "audio.mp3",
    },
    headers={"User-Agent": "MyTikoboxClient/1.0"},
    stream=True,
    timeout=35,
)

if not res.ok:
    raise RuntimeError(res.json()["msg"])

with open("audio.mp3", "wb") as f:
    for chunk in res.iter_content(chunk_size=65536):
        f.write(chunk)
PHP
<?php

$query = http_build_query([
    "url" => "https://sf16.tiktokcdn.com/xxxx/music.mp3",
    "name" => "audio.mp3",
]);

$ch = curl_init("https://tikobox.my.id/api/download" . "?" . $query);
$file = fopen("audio.mp3", "wb");

curl_setopt_array($ch, [
    CURLOPT_FILE => $file,
    CURLOPT_FOLLOWLOCATION => false,
    CURLOPT_TIMEOUT => 0,
    CURLOPT_USERAGENT => "MyTikoboxClient/1.0",
]);

if (!curl_exec($ch)) {
    throw new RuntimeException(curl_error($ch));
}

$status = curl_getinfo($ch, CURLINFO_RESPONSE_CODE);
fclose($file);

if ($status !== 200) {
    unlink("audio.mp3");
    throw new RuntimeException("HTTP $status");
}
