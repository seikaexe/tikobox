Autentikasi

API publik tanpa API key

Di halaman ini
  • Identifikasi Klien
  • Penggunaan dari Browser

Saat ini API tidak memakai autentikasi. Tidak ada API key, token, atau header Authorization yang perlu dikirim

Identifikasi Klien#

Karena tanpa API key, pembatasan request dilakukan per alamat IP. Server juga membaca header User-Agent untuk membedakan klien otomatis dari browser, lihat Rate Limit

Kirim User-Agent yang menjelaskan aplikasi kamu, misalnya:

Header
User-Agent: MyTikoboxClient/1.0

Penggunaan dari Browser#

Response API tidak menyertakan header CORS. Browser di domain lain tidak bisa membaca response fetch ke API ini. Panggil API dari server kamu (backend), lalu teruskan hasilnya ke frontend

Jangan menaruh kunci atau rahasia di request. API ini tidak membutuhkannya
