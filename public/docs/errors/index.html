Penanganan Error

Format error dan cara menanganinya

Di halaman ini

  • Pesan pada Status 502
  • Saran Penanganan

Semua error memakai format yang sama dan status HTTP yang sesuai

Format error
{
  "code": -1,
  "msg": "pesan error"
}
  • code selalu -1 untuk error
  • msg berisi pesan yang aman ditampilkan. Detail teknis internal tidak dikirim ke klien

Urutan Pengecekan#

  1. Cek status HTTP
  2. Parse body sebagai JSON. Bila gagal di-parse, anggap error jaringan atau proxy
  3. Cek code !== 0, lalu baca msg

Jenis Error#

StatusmsgPenyebab
400Link TikTok tidak valid. Tempel link setelah /api/, contoh: /api/https://vt.tiktok.com/xxxxLink kosong atau bukan host TikTok yang didukung
400URL media tidak diizinkan.URL pada /api/download bukan host media TikTok
403Akses ditolak.Scanner keamanan, atau /api/download dipanggil dari halaman situs lain di browser
404Username tidak validInput profil atau hashtag kosong, salah format, atau data tidak ditemukan
502-TikTok gagal diakses atau data tidak tersedia. Isi msg bervariasi, lihat tabel di bawah
504Permintaan terlalu lama, coba lagi.Proses melebihi 28 detik
429Terlalu banyak permintaan. Coba lagi sebentar lagi.Melewati batas request, lihat Rate Limit
405Metode tidak diizinkan.Metode selain GET, HEAD, atau OPTIONS
414URL terlalu panjang.Panjang URL request lebih dari 2500 karakter

Pesan pada Status 502#

msgArti
Video tidak tersedia (privat, dihapus, atau dibatasi wilayah)Konten tidak bisa diakses dari server
TikTok meminta verifikasi (captcha) untuk server ini, coba lagi nantiTikTok menantang server. Ulangi beberapa saat kemudian
Data video TikTok tidak ditemukan di halamanHalaman terbuka tetapi data video tidak ada
Permintaan ke TikTok terlalu lama, coba lagi.TikTok tidak merespons tepat waktu
Link tidak diizinkan.Link atau redirect mengarah ke tujuan yang ditolak oleh validasi keamanan
Gagal memproses URLPesan umum untuk error lain

Saran Penanganan#

  • Status 429: tunggu sesuai retry-after, lalu ulangi
  • Status 502 dan 504: boleh diulang dengan jeda, tetapi batasi jumlah percobaan
  • Status 400 dan 404: perbaiki input, mengulang request yang sama tidak akan berhasil
