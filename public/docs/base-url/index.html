Base URL

Alamat dasar semua request API

Semua endpoint berada di bawah /api/ pada domain Tikobox

https://tikobox.my.id
https://tikobox.my.id/api/
Pada halaman ini, kedua alamat di atas mengikuti domain tempat dokumentasi dibuka. Contoh kode di seluruh dokumentasi juga mengikuti domain yang sama

Aturan#

  • Endpoint API tidak pernah berada di luar /api/
  • Dokumentasi berada di /docs/
  • Response berupa JSON UTF-8, kecuali /api/download yang mengembalikan file
  • Method yang diterima: GET, HEAD, dan OPTIONS
