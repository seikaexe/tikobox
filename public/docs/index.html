Dokumentasi Tikobox API

REST API untuk mengambil video, audio, foto, profil, dan hashtag TikTok

Di halaman ini
  • Mulai Cepat
  • Daftar Endpoint
  • Kategori

Tikobox adalah TikTok Downloader sekaligus REST API untuk developer. Semua endpoint berada di bawah /api/, memakai method GET, dan mengembalikan JSON

Tanpa API key dan tanpa login. Cukup kirim request ke Base URL

Mulai Cepat#

cURL
curl -sS -G "https://tikobox.my.id/api/tiktok" \
  -A "MyTikoboxClient/1.0" \
  --data-urlencode "url=https://vt.tiktok.com/ZSxxxxxxx/"

Lanjut ke Memulai untuk alur lengkap dari mengambil info video sampai menyimpan file

Daftar Endpoint#

MethodEndpointFungsi
GET/api/tiktokInfo video, audio, atau foto dari link TikTok. Detail
GET/api/{link}Bentuk singkat: tempel link setelah /api/. Detail
GET/api/downloadProxy unduh file media. Detail
GET/api/userProfil akun. Juga /api/user/{username} dan /api/@{username}. Detail
GET/api/hashtagStatistik hashtag. Juga /api/hashtag/{name}. Detail
GET/api/healthCek server hidup. Detail
GET/api/Info penggunaan API. Detail

Kategori#

  • Video, Audio, dan Slideshow diambil dari satu endpoint /api/tiktok
  • Profil dan Hashtag untuk data akun dan tagar
  • Fitur yang belum ada, seperti pencarian user dan pemrosesan media, dijelaskan di Belum Tersedia
